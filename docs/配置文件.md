# 配置文件

## 数据类型

### 时间字面量

忽略空格，由数值、单位两部分组成。如果省略单位，默认为微秒。

单位可以为 `us` `usec` `ms` `msec` `s` `sec` `m` `min` 等。

例：`1500000` 等价于 `1500ms` 等价于 `1500 ms` 等价于 `1.5 sec`。

### 空间字面量

忽略空格，由数值、单位两部分组成。如果省略单位，默认为字节。

单位可以为 `B` `Byte` `K` `KiB` `M` `MiB` `G` `GiB` `T` `TiB` 等。

例：`536870912` 等价于 `524288K` 等价于 `512 MiB` 等价于 `0.5G`。
