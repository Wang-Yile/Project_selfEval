## 编程语言

### 语言标记

语言标记是一种简单的描述语言的方法，由语言识别符和标签用冒号连接而成。如果没有标签，冒号可以省略。

语言标记区分大小写。

下表列出各语言默认语言标记。

| 编程语言 | 默认语言标记 |
| :-: | :-: |
| C++ | `c++14:O2` |

#### C++ 语言

识别符为 `c++` 或含 `c++` 前缀的串。

为了程序正常运行，请确保 `g++` 和 `make` 可以通过 `shutil.which` 函数找到。目前没有计划支持其它编译器。

识别符会用于语言标准，即传递给 g++ 的 `-std=` 选项，但 `c++` `c++20` `c++23` `c++26` 会分别被翻译为 `c++14` `c++2a` `c++2b` `c++2c`。

标签：

- `Ox` 启用对应等级优化，例如 `O2` `Ofast`。
- `Dx` 传递宏定义，例如 `DONLINE_JUDGE`。
- `static` 静态链接可执行文件。
- `sanitize` `fsanitize` 检测未定义行为和内存错误，这只在关闭内存限制（例如进入练习模式）时可用。
- `Makefile` 详见 [使用 Makefile](#使用-makefile)。

标签对大小写敏感。

不使用 Makefile 时，默认附加用于静态错误检查的编译选项 `-Wall -Wextra -Wshadow -Wconversion`。

### 使用 Makefile

C++ 语言指定标签 `Makefile` 时，将使用 Makefile 而忽略其它标签。

你需要按照下表编写编译目标，否则会产生编译错误。编译目标同时也是源程序名称和编译得到的可执行文件的名称。

| 模块 | 编译目标 |
| :-: | :-: |
| 选手程序 | program |
| 校验器 | checker |
| 交互库 | interactor |

例如，编译校验器和交互库的 Makefile 可以这样写：

```makefile
checker:
    g++ checker.cpp -o checker -O2
interactor:
    g++ interactor.cpp -o interactor -O2
```

对应语言选项为 `c++:Makefile`。
